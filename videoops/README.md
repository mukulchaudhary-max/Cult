# Cult Video Ops — AI Video Production Project Management & Automation Platform

A specialised hub for an AI video production team. It watches the monthly **Google Sheet** of briefs,
imports every project, **distributes work equally** across available editors, **emails** each teammate their
brief through **Gmail**, detects **every change** made in the sheet, and keeps a full audit trail — so the
project manager stops triaging spreadsheets and starts managing outcomes.

```
Google Sheet ──► monitor ──► detect new / changed rows ──► import ──► assign ──► Gmail
     ▲                              │                         │          │
     └──────── you edit ────────────┴── audit log + notifications + dashboard ◄─ you override anything
```

## Run it (60 seconds)

Requires **Node 22.5+** (uses the built-in `node:sqlite`; no native modules).

```bash
cd videoops
npm install
npm start            # → http://localhost:3000
```

First start seeds a demo workspace: 5 teammates, 35 projects across two months, 5 weeks of
assignment / change / notification / email history — all generated by the real engine, not fixtures.

```bash
npm test             # 33 tests: assignment algorithm, sheet parsing, full sync pipeline
npm run seed         # rebuild the demo workspace
PORT=4000 npm start  # different port
```

## Going live with Google Sheets + Gmail

1. In Google Cloud Console: create a project → enable **Google Sheets API** and **Gmail API** →
   create an **OAuth client ID (Web application)**. Add the redirect URI `http://localhost:3000/auth/google/callback`
   (or `$APP_URL/auth/google/callback`). Add yourself as a test user on the consent screen.
2. Start with credentials:

```bash
export GOOGLE_CLIENT_ID=…  GOOGLE_CLIENT_SECRET=…
export APP_URL=http://localhost:3000        # public URL of the app (used in links inside emails)
export SESSION_SECRET=$(openssl rand -hex 32)   # encrypts stored tokens
export ALLOWED_EMAILS=you@yourcompany.com   # optional allow-list (first sign-in becomes owner otherwise)
npm start
```

3. Open the app → **Sign in with Google** → **Integrations**: paste the Sheet URL → **Connect**, then switch Gmail to **Send via Gmail**.
4. **Settings → Clear all data** to remove the demo teammates/projects, then add your real team in **Team Management**.

Scopes requested: `spreadsheets.readonly` and `gmail.send` only — the app can neither edit your sheet nor read your inbox.

> The live Google paths (OAuth, Sheets read, Gmail send) are implemented in `server/integrations/google.js` over plain
> `fetch`, and the sync/assignment/email logic they feed is covered by tests — but they need real credentials to run, so
> they have not been exercised against Google's servers in this build. Do a dry run with a copy of your sheet before relying on it.

### Sheet format

Any column order and wording works — headers are matched by alias (`Project Name`/`Title`/`Video Name`, `Delivery Date`/`Deadline`/`Due`,
`Assigned To`/`Editor`/`Owner`, …). Unknown columns are kept and **change-tracked too**. The month comes from a `Month` column,
else the **tab name** (`Dec 2026`), else the delivery date. A `Project ID` column is used as the stable key when present;
otherwise projects are matched on month + name, with rename detection by tab + row. See *Integrations → Column mapping*.

## Assignment rules (summary)

- Pending = no assignee, not "Do not auto-assign", not completed. Sheet-named teammates are respected; the rest are distributed.
- **Balance total workload** (default): each project goes to the lowest *total* workload, so 20 projects over 4 equal teammates → 5 each; uneven loads get levelled; remainders go to the lightest loads.
  **Equal share of batch** alternative. Optional priority weighting. Urgent projects are placed first.
- Hard constraints: disabled / unavailable / on leave / owner / capacity cap / excluded type or brand. Soft: preferred types & brands (tie-break, or within ±N projects).
- Manual controls on every project: pick a teammate · **Assign to me** · **Do not auto-assign** · release to automation. Manual choices are never overridden by the sheet (configurable).
- Reassignment: new teammate emailed, previous teammate told, workloads move, history recorded.
